## ✨ 技术与视觉亮点 (Highlights)

- **高性能 Canvas 爱心雨**：高分屏 (Retina DPI) 响应式适配，全屏丝滑飘落不同大小与透明度的魔幻爱心粒子。
- **零依赖 Web Audio 音效**：无需下载外部 MP3 文件，利用浏览器原生 Web Audio API 动态合成点击音效、报错蜂鸣音与终通关合音。
- **磨砂玻璃拟态 (Glassmorphism)**：自适应移动端与 PC 端视觉，支持多巴胺粉色流动渐变背景。
- **极致工程标准化**：
  - 图片体积优化（`sun.jpg` 压缩 97.8% 至 ~75KB 首屏秒开）。
  - 增加 SVG 矢量 Favicon 及完整的 Open Graph 社交卡片标头。
  - 内置 GitHub Actions 自动部署至 GitHub Pages 工作流。

## 💻 本地开发与预览 (Local Development)

项目支持纯静态文件直接打开，也支持现代化前端 Vite 开发服务器 preview：

```bash
# 1. 克隆仓库
git clone https://github.com/crazyzhang277/520-Prank-Review.git
cd 520-Prank-Review

# 2. 安装开发依赖 (可选)
npm install

# 3. 启动本地开发服务器
npm run dev
```

## 🚀 一键部署到 GitHub Pages

仓库已配置好 `.github/workflows/deploy.yml`。

只要在 GitHub 仓库设置中开启 Pages：

1. 打开 GitHub 仓库设置 `Settings` -> `Pages`
2. 将 **Source** 设置为 **GitHub Actions**
3. 每次推送到 `main` 分支即可自动发布上线！
